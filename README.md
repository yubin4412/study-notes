# 1회차 강의 질문 · 숙제

게임 기획 수업 1회차(게임의 구조 · 플레이어 이해)의 강의 원문 질문과 숙제를 같이 쓰는 페이지입니다.
위쪽 탭으로 **강의 원문 질문** / **1회차 숙제**를 바꿔 볼 수 있고, 링크를 가진 사람은 누구나 답을 쓰고 고칠 수 있어요.

| 파일 | 하는 일 |
| --- | --- |
| `index.html` | 사이트 본체 |
| `config.js` | Supabase 주소와 키 (급식 월드컵과 같은 프로젝트) |
| `setup.sql` | 답 저장 표 만드는 SQL |
| `tools/serve.ps1` | 내 컴퓨터에서 미리보기 |

## 처음 한 번만

1. Supabase 대시보드 → **SQL Editor** → `setup.sql` 내용을 통째로 붙여넣고 **Run**
2. GitHub 저장소 **Settings → Pages** → Branch를 `main` / `(root)`로 두고 Save

## 누가 답을 지웠을 때

고치기 전 내용은 Supabase **Table Editor → study_answers_history** 에 남아 있어요.
거기서 내용을 복사해 사이트 칸에 다시 붙여 넣으면 됩니다.
